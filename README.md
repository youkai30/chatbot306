# 🤖 نظام شات بوت ذكي متعدد القنوات مع AI Agent

## 🌟 نظرة عامة

نظام شات بوت ذكي متكامل يجمع بين قوة الذكاء الاصطناعي المتقدم ووكيل ذكي للتحكم في النظام. يوفر المشروع حلولاً شاملة للشركات والمطورين مع دعم متعدد القنوات وتكامل عميق مع المتاجر الإلكترونية.

### 🎯 المكونات الرئيسية
- **شات بوت ذكي**: باستخدام n8n مع DeepSeek AI (توفير 95% من التكلفة)
- **وكيل ذكي (AI Agent)**: للتحكم في النظام وأتمتة المهام
- **لوحة تحكم متقدمة**: لمراقبة الأداء والإحصائيات
- **تكامل متعدد القنوات**: WhatsApp, Telegram, Messenger, Instagram
- **دعم المتاجر الإلكترونية**: Shopify, WooCommerce, Salla وغيرها

## 🚀 المميزات الرئيسية

### 🌐 دعم متعدد القنوات
- **WhatsApp Business API**: تكامل كامل مع واتساب
- **Facebook Messenger**: ردود تلقائية عبر ماسنجر
- **Instagram Direct**: تفاعل مع رسائل إنستغرام
- **Telegram Bot**: بوت ذكي على تيليغرام
- **الموقع الإلكتروني**: شات بوت مدمج في الموقع

### 🤖 ذكاء اصطناعي متقدم
- **DeepSeek AI**: أرخص بـ 95% من OpenAI مع أداء ممتاز
- **AI Agent**: وكيل ذكي للتحكم في النظام
- **فهم النية**: تحليل قصد العميل تلقائياً
- **ردود ذكية**: استجابات طبيعية ومناسبة للسياق
- **تعلم مستمر**: تحسن الأداء مع الوقت

### 🛒 ميزات التجارة الإلكترونية
- **البحث الذكي**: العثور على المنتجات بسرعة
- **تتبع الطلبات**: متابعة حالة الطلبات فورياً
- **إدارة السلة**: إضافة وإزالة المنتجات
- **دعم العملاء**: حل مشاكل الطلبات والإرجاع
- **توصيات ذكية**: اقتراح منتجات مناسبة
- **أتمتة المبيعات**: تذكير السلة المهجورة والعروض

### 📊 لوحة تحكم متقدمة
- **إحصائيات فورية**: مراقبة الأداء في الوقت الفعلي
- **تحليلات عميقة**: تقارير مفصلة عن المحادثات
- **إدارة سهلة**: واجهة بديهية لإدارة النظام
- **مراقبة AI Agent**: تتبع أنشطة الوكيل الذكي

## ⚡ البدء السريع

### الخيار 1: تشغيل الوكيل الذكي (AI Agent) 🤖
```bash
# الانتقال لمجلد الوكيل الذكي
cd ai-agent

# تثبيت المتطلبات
pip install -r requirements.txt

# تشغيل الوكيل الذكي
python run_agent.py

# أو تشغيل على جميع الواجهات
python run_agent.py --host 0.0.0.0 --port 5000
```

### الخيار 2: شات بوت مع DeepSeek (موصى به - توفير 95%!) 💰
1. **إعداد n8n**
   - قم بالتسجيل في منصة n8n
   - استورد ملف `n8n-workflows/chatbot-deepseek.json`

2. **إعداد DeepSeek**
   - احصل على مفتاح API من DeepSeek (مجاني!)
   - راجع `docs/deepseek-setup.md` للإعداد الكامل

3. **دمج الشات بوت**
   - انسخ الكود من `web-integration/chatbot-widget.html`
   - أضفه إلى موقعك الإلكتروني

## 🔧 متطلبات النظام

### للوكيل الذكي (AI Agent):
- Python 3.8+
- pip (مدير الحزم)
- نظام Windows/Linux/macOS
- 4GB RAM (الحد الأدنى)

### للشات بوت:
- حساب n8n (مجاني)
- مفتاح DeepSeek API (مجاني)
- حساب Google Sheets (اختياري)
- موقع إلكتروني للدمج
