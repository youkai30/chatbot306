# 🤖 نظام شات بوت ذكي متعدد القنوات مع AI Agent

## 🌟 نظرة عامة

نظام شات بوت ذكي متكامل يجمع بين قوة الذكاء الاصطناعي المتقدم ووكيل ذكي للتحكم في النظام. يوفر المشروع حلولاً شاملة للشركات والمطورين مع دعم متعدد القنوات وتكامل عميق مع المتاجر الإلكترونية.

### 🎯 المكونات الرئيسية
- **شات بوت ذكي**: يستخدم DeepSeek AI ويتصل بالخادم الخلفي الموحد.
- **وكيل ذكي (AI Agent)**: للتحكم في النظام وأتمتة المهام.
- **خادم خلفي موحد (`real_backend.py`)**: يخدم واجهات برمجة التطبيقات (APIs) والواجهات الأمامية (الشات بوت ولوحة التحكم).
- **لوحة تحكم متقدمة**: لمراقبة الأداء والإحصائيات.
- **تكامل متعدد القنوات (مخطط له)**: WhatsApp, Telegram, Messenger, Instagram.
- **دعم المتاجر الإلكترونية (مخطط له)**.

## 🚀 المميزات الرئيسية

### 🌐 دعم متعدد القنوات
- **الموقع الإلكتروني**: شات بوت مدمج في الموقع (يعمل حاليًا).
- تكاملات مستقبلية مع WhatsApp, Telegram, إلخ.

### 🤖 ذكاء اصطناعي متقدم
- **DeepSeek AI**: لتوفير ردود ذكية (يتطلب إعداد مفتاح API).
- **AI Agent**: وكيل ذكي للتحكم في مهام النظام الأساسية.
- **فهم النية (مع DeepSeek)**: تحليل قصد العميل.
- **ردود ذكية (مع DeepSeek)**: استجابات طبيعية ومناسبة للسياق.

### 📊 لوحة تحكم متقدمة
- **إحصائيات فورية**: مراقبة الأداء من خلال الاتصال بالـ API.
- **تحليلات عميقة**: تقارير مفصلة عن المحادثات (يتم تطويرها).
- **إدارة سهلة**: واجهة بديهية لإدارة النظام.

## ⚡ البدء السريع

### الخطوة 1: إعداد البيئة والمتطلبات
1.  **تأكد من تثبيت Python 3.8+**.
2.  **استنسخ المستودع (Clone the repository)** (إذا لم تكن قد فعلت ذلك بالفعل).
3.  **قم بإنشاء ملف `.env`** في المجلد الجذر للمشروع. يمكنك نسخ `مثال .env` (إذا كان متوفرًا) أو إنشائه يدويًا. كحد أدنى، قد تحتاج إلى:
    ```env
    # لمفتاح DeepSeek AI (احصل عليه من موقع DeepSeek)
    DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

    # مفاتيح سرية لتطبيق Flask و JWT (استبدل هذه بقيم عشوائية وآمنة)
    SECRET_KEY=your_flask_secret_key_here
    JWT_SECRET_KEY=your_jwt_secret_key_here

    # منفذ الخادم (اختياري، الافتراضي 8001)
    # BACKEND_PORT=8001
    ```
4.  **تثبيت المتطلبات (من المجلد الجذر للمشروع)**:
    تأكد من أنك في المجلد الجذر للمشروع ثم قم بتشغيل:
    ```bash
    pip install -r requirements.txt
    ```
    هذا الأمر سيقوم بتثبيت جميع المكتبات الأساسية اللازمة لتشغيل الخادم الخلفي والوكيل الذكي.

5.  **إعداد قاعدة البيانات (إذا كانت هذه هي المرة الأولى):**
    ```bash
    python setup_database.py
    ```

### الخطوة 2: تشغيل النظام
لديك عدة خيارات لتشغيل النظام باستخدام ملفات التشغيل `.bat` (لـ Windows) أو بتشغيل ملفات `.py` مباشرة:

*   **لتشغيل النظام الكامل (الخادم الخلفي الموحد + الوكيل الذكي):**
    ```bash
    # (من المجلد الجذر)
    # على Windows:
    START_FULL_SYSTEM.bat
    # على Linux/Mac (أو يدويًا):
    # 1. شغل الخادم الخلفي في نافذة طرفية:
    #    python real_backend.py
    # 2. شغل الوكيل الذكي في نافذة طرفية أخرى:
    #    python ai-agent/simple_run.py
    ```
    (يمكن أيضًا استخدام `python run_full_system.py` إذا تم تحديثه ليعكس التغييرات)

*   **لتشغيل الخادم الخلفي الموحد فقط (API + واجهة ويب):**
    ```bash
    # (من المجلد الجذر)
    # على Windows:
    START_REAL_SYSTEM.bat
    # أو START_SECURE_SYSTEM.bat (يستخدم نفس الخادم real_backend.py)
    # على Linux/Mac (أو يدويًا):
    python real_backend.py
    ```

### الخطوة 3: الوصول إلى النظام
*   **الواجهة الرئيسية ولوحة التحكم والشات بوت:** `http://localhost:PORT/` (حيث `PORT` هو المنفذ الذي يعمل عليه `real_backend.py`, عادة 8001 أو ما تم تحديده في `.env`).
    *   الصفحة الرئيسية: `http://localhost:PORT/`
    *   الشات بوت: `http://localhost:PORT/web-integration/chatbot-widget.html`
    *   لوحة التحكم: `http://localhost:PORT/dashboard/index.html`
*   **AI Agent API (إذا كان يعمل):** `http://localhost:5000` (المنفذ الافتراضي لـ `ai-agent/simple_run.py`)

### الخطوة 4: إعداد المكونات الاختيارية (مثل DeepSeek و n8n)

#### شات بوت مع DeepSeek (موصى به - توفير 95%!) و n8n 💰
1. **إعداد n8n (إذا كنت ستستخدمه)**
   - قم بالتسجيل في منصة n8n.
   - استورد ملفات سير العمل من مجلد `n8n-workflows/` مثل `chatbot-deepseek.json`.

2. **إعداد DeepSeek AI**
   - تأكد من أنك قد أضفت `DEEPSEEK_API_KEY` إلى ملف `.env` الخاص بك كما هو موضح في الخطوة 1.3.
   - راجع `docs/deepseek-setup.md` (إذا كان موجودًا ومحدثًا) لمزيد من التفاصيل.

## 🎮 التشغيل والاختبار (متقدم)

### تشغيل الوكيل الذكي بشكل منفصل:
```bash
# الانتقال لمجلد الوكيل الذكي
cd ai-agent

# تشغيل الوكيل الذكي
# (المتطلبات الأساسية يجب أن تكون قد ثبتت من الملف الجذري requirements.txt)
python simple_run.py

# أو تشغيل على جميع الواجهات وتغيير المنفذ
# python simple_run.py --host 0.0.0.0 --port 5005
```
(ملاحظة: `run_agent.py` قد يكون إصدارًا أقدم أو مختلفًا، `simple_run.py` هو المشار إليه غالبًا في الأدلة الحديثة.)

### اختبار النظام
- استخدم `quick_test.py` (إذا كان محدثًا) لإجراء فحص سريع.
- قم بالوصول إلى `http://localhost:PORT/api/health` للتأكد من أن الخادم الخلفي يعمل.
- جرب الشات بوت ولوحة التحكم من خلال المتصفح.
